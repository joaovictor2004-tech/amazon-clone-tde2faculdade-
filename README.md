# Amazon Clone (simulação)

Projeto desenvolvido para a disciplina de **Frameworks**.

**Autor:** João Victor Ferreira da Silva

## Sobre o projeto

Simulação do fluxo de compra da Amazon, da tela de login até a página de um produto. É um projeto feito apenas com HTML, CSS e JavaScript puro, sem frameworks ou bibliotecas externas.

## Funcionalidades

- **Login:** validação de e-mail e senha, com mensagens de erro.
- **Página inicial:** banner de ofertas e lista de produtos.
- **Busca:** filtra os produtos pelo nome.
- **Página do produto:** imagem, avaliação, preço, descrição e seletor de quantidade.
- **Carrinho:** botão "Adicionar ao carrinho" com contador no topo da página.
- **Sessão:** o login e o carrinho ficam salvos no navegador (`localStorage`).

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é preciso instalar nada.

## Login de teste

Como é uma simulação, não existe conta cadastrada. Use:

- **E-mail:** qualquer e-mail válido (ex.: `teste@email.com`)
- **Senha:** qualquer senha com 6 ou mais caracteres (ex.: `123456`)

## Estrutura de arquivos

```
├── index.html   # estrutura das telas
├── style.css    # estilos
└── script.js    # lógica (login, busca, produtos e carrinho)
```
